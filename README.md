# 丸の内・銀座 テナント情報の定期収集

GitHub-hosted Actionsで毎日08:00・16:00 JSTに実行します。GitHubの混雑による遅延・実行欠落があり得ます。Actions画面のRun workflowで手動実行できます。

## 範囲
- sources.jsonの公開URL各1ページを確認。robots.txtを尊重し、ログイン・アクセス制限を回避しません。
- 物件詳細リンクの銀座・丸の内関連見出し、および閉店・移転の見出しを「未確認候補」として抽出します。
- 飲食不可は除外しません。一時休業・催事・POPUP見出しは除外しますが、本文確認は人による確認が必要です。
- 本文の変更も媒体別に記録します。変更は新着・閉店の確定を意味しません。
- 全ページ巡回や全文の意味理解は行いません。固定記事URLはその記事の変更監視です。ページ構造によって候補を抽出できない場合があります。
- 取得失敗時は過去候補を残し、確認日時を更新しません。掲載が消えても成約・閉店とは断定しません。

## 保存・反映
data/latest.jsonをコミットし履歴を残します。最大300候補を保持。リポジトリは公開です。サイトがGitHubの公開JSONを読み取り、取得失敗時はサイト内に保存した前回結果を表示します。GitHubからサイトへのPOST送信は利用しません。長期APIキーは不要です。
媒体に取得失敗があると、取得できた結果を保存した後にActionsを失敗扱いにして要確認とします。公開リポジトリで60日間リポジトリの活動がない場合、GitHubにより定期実行が無効になる場合があります。日々の収集結果は毎回コミットされます。

## ローカル検証
Python 3標準ライブラリのみ。python -m unittest -v / python collector.py。
publish.pyは旧方式の診断用で、現在のworkflowからは実行しません。
